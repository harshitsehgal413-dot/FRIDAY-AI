# 🤖 FRIDAY AI

**Your Personal AI Assistant**

FRIDAY AI is a modern personal assistant interface inspired by futuristic AI systems. It is being built to provide an interactive chat experience with a glowing orb interface.

## ✨ Features

- 🌌 Futuristic interface
- 🔵 Animated glowing orb
- 💬 Chat interface
- 📱 Responsive design for desktop and mobile
- 🚀 AI integration planned

## 🛠️ Built With

- React
- Vite
- CSS
- JavaScript

## 💻 Run Locally

1. Install [Node.js](https://nodejs.org/).
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🔐 Security

Never publish API keys, passwords, or `.env` files.
